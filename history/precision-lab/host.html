Renderer diagnostics
Rendering pauses while this panel is open. The report preserves the measurements captured before pausing. GPU timing is shown only when supported; completion delay is not GPU execution time.
This is an experimental multi-pass procedural raster renderer, not the original single-fragment ray marcher. Native-device 60 fps is not verified. Machined geometry is parametrically rebuilt with explicit bevels. Studio mode traces up to ten surface or glass interactions and accumulates native-resolution samples. Live mode uses baked diffuse lighting plus geometry-traced secondary rays; cached optics remain an explicit fallback. Studio is a still-view refinement mode, not a 60-fps animation renderer.
